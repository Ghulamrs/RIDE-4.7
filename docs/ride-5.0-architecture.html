▼assemble and link
4 · Assembler, linker and runtime for each target

x86_64-linux

  • Assembler and linker: the system's, through cc/c++
  • Runtime: glibc, libstdc++
  • Output: ELF program

x86_64-windows

  • Assembler: masm MASM/src (cpp11 gets -masm=masm), or Visual Studio's ml64
  • Linker: link LINK/src if named under Tools, else Microsoft's link.exe
  • Runtime: the Microsoft CRT
  • Output: PE .exe

arm64-darwin

  • Assembler and linker: Apple's clang toolchain
  • Runtime: libSystem, libc++
  • Output: Mach-O program

tms6747

  • Assembler: asm6x ASM6x/src; output TI ELF .obj
  • Linker: lnk6x LNK6x/src
  • Runtime: rts6x.lib / rts6xd.lib RTS6x/src
  • Shalimar also links shmrt6x.lib / shmrt6xd.lib
  • Output: .out
